# 评论隐藏审计的游标分页

本文解释 Phase 7H 已实现的单动态审计分页契约。选定本轮实现、迁移和运行验证已完成；这份笔记解释设计，具体证据与未验证范围以阶段记录为准。

## 游标表示什么

路由 `GET /admin/blog-comments/hide-audits/of/blog/{blogId}` 只允许 ADMIN。`blogId` 选择动态，`beforeId` 是隐藏审计行的 ID。它不是被隐藏评论的 ID。第一页不传 `beforeId`；下一页把上一页响应的 `nextBeforeId` 原样传入。

查询使用 `blog_id = blogId`，有游标时再加 `id < beforeId`，按 `id DESC` 返回。严格小于会排除上一页末尾那行。`size` 默认 20，范围为 1..50；不认识的 query 参数忽略。

## 为什么多查一行

数据库最多取 `size + 1` 行。若实际取到第 `size + 1` 行，页面只返回前 `size` 行，并令 `hasNext=true`；多出的行不进入响应。下一页游标取最后一个已返回项目的审计 ID，而非 lookahead 行的 ID。若没有多出行，`hasNext=false`，`nextBeforeId` 为 null，响应序列化后省略这个字段。

页面 envelope 是 `items`、`hasNext`、`nextBeforeId`。`items` 复用 7G 八字段 DTO：四个 ID 都用十进制字符串，reason 是字符串，状态是 Integer，createTime 是 LocalDateTime。这样既不改变单条查询的字段白名单，也避免 Java Long ID 被 JavaScript number 舍入。

## 空结果和历史记录独立性

不存在的 blogId、没有隐藏记录和游标后没有记录都返回 HTTP 200 空页。查询不先检查 blog 是否存在，也不 join blog、comment 或 operator 表。只要审计行仍被保留，它就不依赖这些当前业务行存在；接口表达的是审计表中这次查询快照可见的记录，不推断评论当前状态。

匿名、停用或无效/未知角色身份为 401；有效 USER/MERCHANT 为 403；非法/超范围 ID 和 size 为 400；数据库访问错误转为不暴露 cause 的通用 500。有效 ADMIN 查询是只读操作。

## 单页一致性与跨页并发

一个请求在自己的只读 REPEATABLE READ 事务中执行普通 SELECT，配置 5 秒 JDBC 查询超时，不是端到端 SLA；DDL 元数据锁和其他数据库延迟不在保证内。它不锁定业务行，不改状态或计数，也不 COUNT。下一页是另一个请求和另一个快照，因此不会自动接续第一页的数据库快照。

自增 ID 在事务插入时分配，提交可能乱序。比如事务 A 先拿到较小 ID 后暂停，事务 B 拿到较大 ID 并先提交；读者可能先看到 B 并继续向更小 ID 翻页。A 随后提交时，它的 ID 可能已经落在读者的游标之后，读者不会再看到它。故 `id DESC` 是稳定的分页键，但不代表提交时间顺序，游标也不是跨页 watermark。若产品要求绝不漏记录，需要另外设计冻结边界或复查协议，不能把当前契约说成具备该保证。

## V009 索引边界

候选索引是 `(blog_id, id)`，对应 V009。它的列顺序与按 blog 过滤、按 id 游标扫描的条件相匹配，但索引设计本身不证明数据库一定选择该索引或达到某个性能数字。已有卷须先备份并人工确认 V008 表及索引定义，再审查并应用迁移；同名错误形状不自动修复。回退旧应用可保留索引，不自动删除，也不恢复业务状态或计数。

本轮 40 项定向检查、374 项 Java 8 默认统计（4 项设计跳过）、49 项显式真实 MySQL IT 和 25 组目标 Compose 通过。验证覆盖审计 ID 游标、保留孤立元数据、未提交与回滚的隐藏不被读取，以及 V009 重复/缺表/同名错误形状；50+1 边界使用合成导入元数据，不冒充 51 次应用隐藏。

不在这份分页契约中的能力包括全局列表、总量、导出、审计修复、状态/计数写入、UI 和跨页一致快照。未测索引执行计划/优化器选择、性能收益、生产 DDL 锁/耗时或生产负载。
