# Phase 7F：管理员一级评论隐藏与审核记录

日期：2026-10-11。前置源码为 7E 最终提交 `1573a18f99bb24b227867269eca62c57f110bed1`；干净 main 起步，远端起点只读核验一致。原始教学仓库及要求文档未修改。

## 最小范围与不变量

- 新增应用端 `POST /admin/blog-comments/{commentId}/hide`；专用 Controller 使用 `hasRole('ADMIN')`，可处理本人/他人正常一级评论。USER/MERCHANT 即使是作者也不能使用；没有在作者撤回入口放宽管理员权限。
- Path 为正 Java Long，JSON 仅接收 reason，非空白、最多 255 个 Java UTF-16 字符单元；未知字段忽略。操作人来自会话，不接受客户端 operator/status/blogId。成功 HTTP 200、`{"success":true}`，不返回 data 或原文/审核原因。
- 所属动态存在、parent_id=answer_id=0、status=0 才首次隐藏。先普通定位 id/blog，再锁动态、当前读锁根并复核同动态/关系/状态；0→2、旧 comments 递减（NULL/0 下限 0）、审核 INSERT 同一事务，每步影响行数须 1，否则 422 整体回滚。方法内 Mapper DataAccessException 变通用 500，不带驱动 cause。
- status=2 仅有同 comment/blog、from=0/to=2 审核记录时重复成功。审核读取也用 FOR UPDATE 当前读；重复不更新状态/计数或覆盖首次操作人/原因，包括其他管理员携带不同有效原因的重试。未审计的旧 2、1/3/NULL/其他状态、回复或非法关系、缺失目标/动态均 404，不猜测历史事实。
- 保留原文、关系及全部回复行/状态，不级联扣回复数。隐藏根从一级列表排除，提交后开始的新请求对其回复列表/创建为 404；回复作者仍可独立使用 7D 撤回。根作者不能把 2 改成 3，作者撤回先完成时隐藏为 404。既有只读 RR 快照可能读到旧内容；先取得动态锁的回复创建仍可能成功，不宣称所有并发创建都拒绝。
- V008 新建 `tb_blog_comment_hide_audit`：comment/blog/operator、原因、0→2、数据库时间，comment_id 唯一。仅本用例 INSERT，无应用更新/删除入口；不存原文副本，不加外键，不宣称防数据库管理员篡改。冲突的旧审核行会使 INSERT 失败并回滚，不自动覆盖/修复。
- API 目录为 44 个应用显式映射、13 个 Controller：原评论 6 条 + 管理员隐藏 1 条。此业务路由使用应用端口，独立 Actuator 管理面两个 GET 仍单列；source_revision 保持目录初建来源。

无回复审核、举报工作流、恢复、级联/物理删除、审核列表/查询、通知、前端、任意状态编辑、创建幂等键、历史关系/计数回填或完整管理后台。comments 仍是旧增减聚合，不保证等于可见数；保留原文不是隐私抹除。

## 数据库升级与回退

Fresh 空库初始化现在按 schema → V001…V008 → synthetic seed 执行。已有卷不会因重启自动迁移：先备份，核对已有 V006/V007 及审核表定义，再应用 V008，之后升级应用。CREATE TABLE IF NOT EXISTS 只按表名跳过，不校验/修复同名错误结构；DDL 非业务事务、可能锁定资源，不是旧脏库迁移验收。

回退旧应用可保留审核表/数据，旧 status=0 列表仍排除隐藏根；不得自动删表、恢复状态/计数或把 2/3 混用。数据修复、恢复、保留周期及共享库升级另定范围。
